# invariants/ — INV500 folded (ledger 1.5)
500 cascade invariants = 50 scenarios x 10. `scenarios.json` is the index: each scenario names the harness assertion
(G1-G9) or the ledger phase that enforces its cascade. The 10th invariant of each scenario is a golden-set fixture.
This is the folded encoding (50 enforceable scenarios, not 500 loose files); per-scenario assertions are filled in as
each phase lands.
